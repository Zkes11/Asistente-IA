# Prolog academico

Esta carpeta mantiene una representacion Prolog equivalente y simplificada de reglas y relaciones vocacionales.

- `vocational.pl`: hechos y predicados de referencia.
- `examples.pl`: estudiantes de ejemplo.
- `../training/export_rules_to_prolog.py`: genera una salida Prolog a partir del YAML canonico.

Si SWI-Prolog no esta disponible, las pruebas de paridad deben omitirse explicitamente.
