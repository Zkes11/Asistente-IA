# API Guide

Base path: `/api/v1`

Flujos disponibles en esta iteracion:

- autenticacion por correo y contrasena,
- perfil y onboarding,
- cuestionario versionado con respuestas parciales,
- generacion de recomendaciones,
- exploracion de programas,
- plan de accion,
- chat determinista,
- exportacion y solicitud de eliminacion.

OpenAPI queda disponible en `/openapi.json`.
